# RentEase frontend

React 19 + Vite. See the [main README](../README.md) for setup, configuration and the project overview.

```powershell
npm install     # first time
npm run dev     # http://localhost:5173 (expects the API at VITE_API_BASE_URL in .env)
npm run build   # production build in dist/
npm run lint    # oxlint
```
